# RAG — Odoo 19.0 documentation link index (JAOM-relevant subset, EN + ES)

Links only, no content. Source: the global toctree embedded in the Odoo 19.0
docs home page (https://www.odoo.com/documentation/19.0/), cross-checked against
the section index pages. Scrape date: 2026-09-12; trimmed 2026-09-20 to the
sections this project touches. Each kept page is listed twice: English
(canonical, path root) and Spanish (`/19.0/es/`). Kept: root/index pages,
essentials, general (companies, users, email — no IoT, no third-party
integrations), core accounting (no per-country fiscal localizations, no payment
providers), inventory & MRP, shipping, fleet, developer documentation,
administration. Dropped: all other applications, contributing, and the other
16 language versions under `/19.0/<lang>/`. Structure note: in Odoo 19 the
older top-level doc sections no longer exist as separate trees; webservices/
(XML-RPC/JSON-RPC API) and upgrade/ content were merged into
`developer/reference/` and `administration/`.

Re-scrape from the home toctree if a dropped page is ever needed.
